# コードナビ ギター

スマホで使うギター作曲用のコードアシスト（PWA）。次のコード候補、自動伴奏、押さえ方、スケール、ジャズスタンダード集、スキャット録音（動画MP4／音声MP4／MP3で保存）。

ブラウザで開いて「ホーム画面に追加」するとアプリとして使えます。録音にはマイクの許可が必要です（HTTPSで公開したページのみ）。

## 使っている素材・ライブラリ
- ギター・ベース・ビブラフォンの音源: FluidR3_GM SoundFont（Frank Wen, CC BY 3.0）を gleitz/midi-js-soundfonts 経由で一部抜粋
- mp4-muxer・webm-muxer（Vanilagy, MIT）
- lamejs（LGPL-3.0）
